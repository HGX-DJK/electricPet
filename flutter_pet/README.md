# 桌面萌宠 · 波可 (Poko) - Flutter 跨平台移动端

基于 Google Flutter 框架与高性能 `CustomPainter` 原生矢量数学渲染引擎打造的跨平台桌面/移动萌宠应用。

---

## 🌟 核心特色与特性还原

1. **纯代码矢量实时渲染（无序列帧臃肿大图）**
   - 1:1 还原桌面端算法：自然骨骼呼吸律动、耳朵微颤、随手势靠近动态瞳孔放大、二次元动漫高光星芒。
   - 自然双重眨眼与抚摸弯弯笑眼形变。
   - 5 大经典花色：三花小猫、雪球白猫、元气橘喵、玄夜黑猫、暹罗猫咪。

2. **14 大多样才艺动作秀**
   - 📦 纸箱藏猫猫（真实瓦楞纸箱纹理与露头大眼睛）
   - 🐭 喵影神捕（扑击小老鼠）
   - 🧶 粉红毛线球（抱团打滚）
   - 👀 贴边探头偷看（吸附在手机左右边框探头观察）
   - 🫧 洗脸理毛、🥱 伸懒腰、❓ 歪头卖萌、⭐ 眩晕星星等。

3. **灵动伴侣岛（仿 iOS 灵动岛马卡龙胶囊操作栏）**
   - 🍱 **美食厨房**：8 款珍馐美食（金枪鱼罐头、冻干三文鱼等）。
   - 👗 **魔法衣橱**：切换猫咪品种与铃铛项圈挂件。
   - 📝 **随手灵感便签**：4 款马卡龙粉彩主题（奶杏黄、落樱粉、薄荷绿、晴空蓝），支持一键时间戳与本地持久化。
   - 🫧 **洗澡沐浴** 与 🌙 **哄睡唤醒**。

4. **双模运行架构**
   - **沉浸乐园主模式**：全屏触控抚摸、物理重力落地、亲密度成长。
   - **Android 全局悬浮窗模式**：通过 `SYSTEM_ALERT_WINDOW`，悬浮在微信、桌面与任意 App 上层自由拖拽陪伴。

## 🚀 快速运行与打包

### 1. 运行调试
在项目根目录执行：
```bash
cd flutter_pet
flutter pub get
flutter run
```

### 2. 打包生成 Android APK
```bash
cd flutter_pet
flutter build apk --release
```
编译生成的安装包位于：`build/app/outputs/flutter-apk/app-release.apk`。

### 3. 支持平台
- 🤖 **Android** (手机 / 平板 / 车机)
- 🍎 **iOS** (iPhone / iPad)
- 💻 **Windows / macOS / Linux / Web**
