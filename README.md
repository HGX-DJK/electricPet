# 桌面萌宠 · 波可 (Desktop Pet Poko) 🐾

> 一款基于 PyQt6 开发、轻量流畅、支持在 Windows 系统上安装与常驻的治愈系透明桌面电子宠物与番茄钟伴侣。

### 3. 🎭 多样化动作体系与自主才艺秀 (超丰富的动态绝活！)
支持自主 AI 随机演练与随时主动点播的 **8 大专属动作生态**，每一项动作均配备独立的骨骼形变、微表情动画、专属合成音效与治愈台词：
- 🐱 **伸个懒腰打哈欠 (`STRETCH_YAWN`)**：四肢平铺拉伸，双眼眯缝 `> <`，张大嘴巴露出粉嫩小舌头，吐出可爱哈欠气泡。
- 🐾 **萌爪洗脸理毛 (`WASH_FACE`)**：微笑弯弯眼 `^ ◡ ^`，举起粉色小肉垫在脸颊与胡须旁规律循环揉搓擦洗。
- 🦋 **欢快抓扑彩蝶 (`CHASE_BUTTERFLY`)**：空中飞来翩翩起舞的荧光蓝蝴蝶，萌宠欢欣起跳、高高扬爪扑腾追逐。

## 🚀 安装与启动方式

1. **一键安装至 Windows (推荐)**：
   - 双击运行 **`installer/setup.bat`**。
   - 自动安装至系统用户目录，在**桌面**和**开始菜单**创建高清图标快捷方式，并注册到 Windows 设置**「已安装的应用」**列表中（支持标准卸载）。
2. **免安装独立版直接运行**：
   - 双击运行 **`dist/DesktopPet/DesktopPet.exe`** 即可立即唤出萌宠。
3. **源码运行**：
   - 双击 **`run.bat`** 或在终端执行 `python main.py`。

## 📱 Flutter 跨端版构建 (含 AI 语音陪伴功能)

`flutter_pet/` 目录是与桌面版对齐的 Flutter 跨端实现 (Android / iOS / Windows / macOS / Web)。

```bash
cd flutter_pet
flutter build apk --release --no-tree-shake-icons
```

- **AI 能力开箱即用**：MiniMax 云端大模型 + 萌系小奶音的密钥已内置在
  `flutter_pet/lib/config/ai_config.dart` 的 `defaultMinimaxApiKey` 中, 换密钥改这一行即可。
- 也可在 App 内 **⚙️ 设置** 面板手动填写 Key (保存在本机 SharedPreferences), 优先级高于内置值。
- 密钥来源：MiniMax 开放平台 <https://platform.minimaxi.com/> → 账户管理 → 接口密钥。

## 🎮 常用快捷操作

- **鼠标右键点击宠物**：打开毛玻璃快捷互动菜单（喂食成长、萌宠衣橱、玩耍互动、沐浴、睡觉、专注、状态等）。

- **鼠标左键点击/抚摸宠物**：摸摸头触发呼噜声与爱心飘落。
- **鼠标双击宠物**：开心欢跃互动。
